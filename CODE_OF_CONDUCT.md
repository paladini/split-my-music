# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment, discrimination, personal attacks and publishing others' private information are not tolerated.

Maintainers may remove comments, commits or contributions that violate this code and may ban repeat offenders. To report a problem, open a private security advisory on GitHub or contact the maintainer (Fernando Paladini, via his GitHub profile).
